HOW TO USE AERODOC

1 Document Ingestion & Parameters

Drag and drop any PDF file into the dropzone or click Load Sample Test PDF to test immediately. Configure toggles like Base64 image embedding (for single-file standalone markdown), YAML frontmatter, and multi-column unrolling.

2 Visual Inspection & Verification

The studio displays a live split-pane: the original high-resolution PDF page on the left, and the synthesized Markdown on the right. You can navigate through pages, inspect tables, examine rendered KaTeX math equations, and toggle between Split, Rendered, and Raw code views.

3 1-Click Antigravity Export

Click Copy to copy the entire markdown artifact to your clipboard, or click Download .MD. Each download automatically receives a unique timestamped filename, and server-side temporary files are zeroed out and purged immediately after transmission.

4 Keyboard Shortcuts & CLI

Press Ctrl + Enter to trigger conversion.
Press Esc to dismiss this guide.
Or run via CLI: python -m aerodoc.cli convert file.pdf -o out.md --embed-images
