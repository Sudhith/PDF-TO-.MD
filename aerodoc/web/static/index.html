AERODOC ARCHITECTURE & SYSTEM SPECIFICATION

01 Universal Document Ingestion

AeroDoc ingests PDF, Word DOCX/DOC, Plain Text, HTML, and CSV data. Format-specific abstract syntax tree (AST) engines normalize headings, tables, bullet hierarchies, and code blocks into a common structural stream.

02 Antigravity Callouts & KaTeX Transpilation

Visual callout containers and inline alerts are transformed directly into Antigravity standard alerts: > [!NOTE], > [!WARNING], > [!TIP], and > [!IMPORTANT]. Mathematical notations and LaTeX expressions are wrapped into KaTeX blocks.

03 Ephemeral Security & Unique Namespace

Every download generates a cryptographically salted unique filename. Once transmission completes, background tasks zero out the disk bytes and delete temporary server storage immediately.

04 Operational Controls & Shortcuts

Trigger conversion: Ctrl + Enter
Close modals: Esc
CLI execution: python -m aerodoc.cli convert file.docx -o output.md
